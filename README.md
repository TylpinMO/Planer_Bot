# 🤖 PlanerBot - Telegram Task Manager

Умный бот-планировщик задач для Telegram с системой уведомлений и премиум-подпиской.

## ✨ Основные возможности

### Бесплатная версия

- 📋 1 список задач
- ✅ Неограниченное количество задач
- 🔔 1 уведомление на весь список
- ⏰ Настройка часового пояса
- 📊 История выполненных задач

### Премиум (250 ⭐ Telegram Stars)

- 📋 До 10 списков задач
- 🔔 Индивидуальные уведомления для каждой задачи
- 📊 Ежедневная сводка со всеми задачами
- ⚡ Приоритетная поддержка

## 🚀 Быстрый старт

### Локальная разработка

```bash
# Клонирование
git clone https://github.com/YOUR_USERNAME/PlanerBot.git
cd PlanerBot

# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate  # Linux/Mac

# Установка зависимостей
pip install -r requirements.txt

# Настройка конфигурации
cp .env.example .env
nano .env  # Укажите BOT_TOKEN и ADMIN_IDS

# Запуск
python main.py
```

### Развертывание на сервере

📖 **Полная инструкция:** [DEPLOY.md](DEPLOY.md)

Быстрое обновление:

```bash
./update.sh
```

## 🔧 Конфигурация

Создайте файл `.env`:

```env
BOT_TOKEN=your_bot_token_from_botfather
ADMIN_IDS=123456789
DATABASE_URL=sqlite+aiosqlite:///planner.db
```

## 🛠 Технологии

- **Python 3.9+**
- **aiogram 3.4.1** - Telegram Bot Framework
- **SQLAlchemy 2.0.25** - ORM
- **APScheduler 3.10.4** - Планировщик уведомлений
- **SQLite** - База данных

## 📖 Команды

### Пользовательские

- `/start` - Главное меню
- `👤 Профиль` - Статистика и настройки
- `ℹ️ Помощь` - Руководство

### Админские

- `/give_premium_forever USER_ID` - Бесконечная подписка
- `/give_premium USER_ID [DAYS]` - Выдать премиум
- `/stats` - Статистика

## 🔔 Уведомления

- **Списки:** Уведомление со всеми задачами списка
- **Задачи (премиум):** Индивидуальное напоминание
- **Сводка (премиум):** Ежедневная сводка всех задач

## 🔄 Обновление

```bash
./update.sh
```

Скрипт автоматически:

- Создаст backup базы данных
- Скачает обновления с GitHub
- Применит миграции
- Перезапустит бота
